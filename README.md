# Warn & Alarm

Windows 시작 시 오늘의 체크리스트로 화면을 가리고, 모든 항목을 체크해야 풀리는 데스크톱 앱.
자리 비움을 감지해 복귀 후에는 일정 간격으로 스트레칭 알림을 띄웁니다.

## 동작 요약

| 기능 | 설명 |
| --- | --- |
| 차단 화면 | 실행되면 전체 화면(kiosk)으로 체크리스트를 표시. 모니터가 여러 개면 나머지 화면도 함께 덮습니다. |
| 완료 | 모든 항목을 체크하면 하단에 **모두 완료 · 화면 열기** 버튼이 나타나고, 누르면 트레이로 내려갑니다. |
| 하루 리셋 | 시스템 시각 기준 **매일 01:00**(설정 변경 가능)에 체크가 모두 풀립니다. 쓰고 있는 도중에는 화면을 가로채지 않고 알림만 보냅니다. 차단 화면은 **앱을 시작할 때(보통 부팅할 때)** 만 뜹니다. |
| 긴급 해제 | 차단 화면 우측 하단의 흐린 `긴급 해제` → 5초 길게 누르기 → 확인 코드 입력 + 사유 20자 → 15분 / 1시간 / 오늘 하루 중 선택. 기록이 설정 화면에 남습니다. |
| 자리 비움 | 설정한 시간(기본 5분) 동안 입력이 없으면 자리 비움. 이때는 알림을 보내지 않습니다. |
| 스트레칭 알림 | **화면이 열린 시점**과 **자리 비움에서 복귀한 시점**부터 설정한 간격(기본 1시간)으로 알림을 띄웁니다. 간격은 1분부터 지정할 수 있습니다. |
| 취침 준비 알림 | 매일 정해둔 시각(기본 23:00)에 **화면 가운데 달 모양 창**이 뜹니다. 누를 때까지 남아 있고, '조금 뒤에 다시'로 미룰 수 있습니다. |
| 일정(달력) | 별도의 **달력 창**에서 날짜를 눌러 **제목+내용**으로 일정을 등록/수정/삭제합니다. 달력 창 아래 **다가오는 일정** 칸에 오늘 이후 일정이 **가까운 날짜순**으로 보이고, 날짜가 지나면 목록에서 빠집니다(달력엔 그대로 남음). |
| 할 일 → 달력 | 매일 할 일을 마치면 달력 창이 자동으로 떠서 다가오는 일정을 보여줍니다. (설정에서 끌 수 있음) 트레이 → 일정 달력, 또는 체크리스트 창의 📅 버튼으로도 엽니다. |
| 설정 옮기기 | 설정 화면에서 파일(.json) 또는 `WA1-` 로 시작하는 코드로 내보내고 불러올 수 있습니다. 등록한 일정도 함께 옮겨집니다. |
| 트레이 상주 | 창을 닫아도 트레이에 남습니다. 아이콘 클릭 → 체크리스트, 우클릭 → 설정 / 종료. 이미 켜져 있는데 실행 파일을 다시 실행해도 같은 창이 뜹니다. |
| 설정 열기 | 체크리스트 창 오른쪽 위 톱니바퀴 버튼. 차단 중에는 숨겨집니다. |

차단 중에는 트레이의 **설정**과 **종료**가 잠깁니다. (설정에서 할 일을 지워 차단을 우회하는 것을 막기 위함)

## 실행 파일

두 가지를 만들어 두었습니다.

- `dist/WarnAndAlarm 1.0.0.exe` (68MB) — 설치 없이 더블클릭하면 실행되는 단일 파일.
  실행할 때마다 임시 폴더에 풀고 시작하므로 첫 화면이 뜨기까지 몇 초 걸립니다.
- `dist/WarnAndAlarm-1.0.0-win-x64.zip` (103MB) — 압축을 푼 폴더 안의 `WarnAndAlarm.exe` 를 바로 실행.
  풀어놓는 과정이 없어 훨씬 빨리 뜹니다. **시작 프로그램으로 쓸 거라면 이쪽을 권합니다.**

### '게시자를 확인할 수 없습니다' 경고 없애기

실행 파일에는 자체 서명 인증서로 서명이 들어가 있습니다. 그 인증서를 이 컴퓨터가 신뢰하게 만들면
경고가 사라집니다. **`certs/인증서-설치.ps1` 을 오른쪽 클릭 → "PowerShell에서 실행"** 한 번이면 끝입니다
(관리자 권한 필요). 되돌리려면 `certmgr.msc` 에서 'Warn & Alarm' 인증서를 지우면 됩니다.

관리자 권한 없이 현재 사용자에게만 넣으려면 PowerShell에서:

```powershell
Import-Certificate -FilePath .\certs\codesign.cer -CertStoreLocation Cert:\CurrentUser\Root
Import-Certificate -FilePath .\certs\codesign.cer -CertStoreLocation Cert:\CurrentUser\TrustedPublisher
```

되돌리는 방법은 **[certs/인증서-제거방법.md](certs/인증서-제거방법.md)** 에 적어 두었습니다.
설치하지 않고 그냥 쓰려면 처음 한 번 **추가 정보 → 실행** 을 누르면 됩니다.

**SmartScreen 파란 화면("인식할 수 없는 앱")은 서명과 별개입니다.** 파일에 붙는 다운로드 표시
(Mark of the Web) 때문에 뜨므로, `\\wsl.localhost\...` 같은 네트워크 경로가 아니라
로컬 폴더(예: `C:\Users\<사용자>\Downloads`)에 두고 실행하세요. 인터넷에서 받은 파일이면
속성에서 **차단 해제**에 체크하거나 `Unblock-File` 을 쓰면 됩니다.

> 공인 기관에서 발급받은 인증서가 아니라서, 인증서를 신뢰 목록에 넣은 컴퓨터에서만 경고가 사라집니다.
> 다른 사람에게 파일을 주면 그 컴퓨터에서는 여전히 경고가 뜹니다.
> 인터넷에서 내려받은 파일이라면 SmartScreen 경고가 따로 뜰 수 있는데, 그건 서명과 무관하며
> 파일 속성에서 **차단 해제**에 체크하면 없어집니다.

## 직접 빌드하기

```bash
npm install            # electron 내려받기
npm start              # 개발 실행
npm run dist:portable  # 단일 exe -> dist/
npm run dist           # 설치본(NSIS) + 단일 exe (Windows 또는 wine 필요)
```

리눅스/WSL에서는 `dist:portable` 만 됩니다. NSIS 설치본은 빌드 도중 설치 파일을 한 번 실행해
언인스톨러를 만들기 때문에 Windows나 wine이 있어야 합니다.

exe 아이콘과 버전 정보는 보통 rcedit(wine)이 넣지만, 이 프로젝트는 `scripts/brand-exe.js` 가
순수 JS(`resedit`)로 처리하므로 wine 없이도 아이콘이 제대로 붙습니다.

## 시작 프로그램 등록

`Win + R` → `shell:startup` → 열린 폴더에 실행 파일(또는 그 바로가기)을 넣으면 됩니다.

## 설정

트레이 우클릭 → **설정**. 저장을 눌러야 반영됩니다(`Ctrl + S` 도 동작).

- **할 일 목록** — 추가 / 수정 / 삭제. 순서는 **왼쪽 번호를 잡고 끌어서** 바꾸거나 ↑↓ 버튼으로 바꿉니다.
  입력창에 적고 Enter 를 누르면 바로 다음 항목을 이어서 입력할 수 있습니다. 목록이 비면 차단 화면이 뜨지 않습니다.
- **하루 리셋 시각** — 기본 01:00. 이 시각을 기준으로 "하루"가 나뉩니다.
- **자리 비움 판정** — 1분부터.
- **스트레칭 알림 간격** — 1분부터.
- **스트레칭 알림 사용 / 차단 중 창 강제 유지 / 앱 시작 시 체크리스트 표시 / 할 일을 마치면 달력 열기** 스위치.
- **알림 방식** — 자동 / 트레이 풍선 / 시스템 알림. 옆의 **테스트** 버튼으로 바로 확인할 수 있습니다.
- **취침 준비 알림** — 사용 여부, 알림 시각, 다시 알림 간격, 창에 표시할 문구. **지금 미리보기** 로 확인할 수 있습니다.
- **설정 내보내기 / 불러오기** — 파일로 저장하거나, 클립보드에 복사되는 짧은 코드(`WA1-…`)로 옮깁니다.
  할 일 목록과 시간·동작 설정만 담기며, 오늘 체크한 내용과 긴급 해제 기록은 옮기지 않습니다.

설정 화면 맨 아래에 **버전과 빌드 시각**이 표시됩니다. 새로 받은 실행 파일로 돌고 있는지 여기서 확인할 수 있습니다.

설정과 오늘 상태는 **`%APPDATA%\Warn & Alarm\warn-and-alarm.json`** 에 저장됩니다.
(예: `C:\Users\<사용자>\AppData\Roaming\Warn & Alarm\warn-and-alarm.json`)
실행 파일을 어디에 두든, 새 버전으로 바꿔도 이 파일은 그대로 남습니다. 설정 화면 맨 아래에 현재 경로가 표시됩니다.

## 구조

```
src/
  assets/            실행 중 쓰는 아이콘 (체크 아이콘 + 취침용 달 아이콘)
  main/main.js       창·트레이·알림·자리 비움 감지·IPC
  main/store.js      설정/상태 저장, 하루 경계 계산, 완료·차단 판정
  preload/preload.js contextBridge 로 노출하는 API
  renderer/
    checklist/       차단 화면 + 긴급 해제 절차
    settings/        설정 화면
    bedtime/         취침 준비 알림 창
    calendar/        일정 달력 창
    cover/           보조 모니터 커버 화면
    shared/base.css  공통 토큰과 컴포넌트
scripts/make-icon.js     아이콘(PNG/ICO) 생성 — 의존성 없음
scripts/make-cert.js     자체 서명 인증서 생성 (openssl)
scripts/brand-exe.js     exe 에 아이콘·버전 정보 삽입 + 서명 (wine 불필요)
scripts/sign-exe.js      Authenticode 서명 (규격대로 계산한 PE 해시 사용)
scripts/sign-artifacts.js 완성된 결과물 서명
build/icon.ico           설치본·exe 아이콘용 패키징 리소스
certs/                   서명 인증서와 설치 스크립트 (개인 키는 git 에서 제외)
```

## 알아둘 점

- 차단 화면은 **앱을 시작할 때만** 뜹니다. 컴퓨터를 쓰는 도중에 리셋 시각이 지나면 체크만 비워지고
  알림으로 알려줍니다. 다만 긴급 해제에서 '15분 뒤에 다시'처럼 직접 미룬 경우에는, 정한 시간이 지나면
  다시 화면을 가립니다(그렇게 하려고 고른 것이므로).
- 차단은 "전체 화면 + 항상 위 + 포커스 되돌리기"로 구현한 **소프트 차단**입니다. 작업 관리자로 프로세스를 끝내면 풀립니다. 의지를 돕는 장치이지 강제 잠금 장치는 아닙니다.
- **알림이 안 보인다면**: Windows는 설치하지 않고 실행한 앱(포터블 등)의 시스템 토스트를 조용히 무시하는 경우가 있습니다.
  그래서 Windows 기본값은 *트레이 풍선* 이고, 설정 화면에서 방식을 바꿔가며 **테스트** 버튼으로 확인할 수 있습니다.
  집중 지원(방해 금지)이 켜져 있으면 어느 방식이든 알림 센터에만 쌓입니다.
- 절전에서 깨어나면 자리 비움 복귀로 간주해 스트레칭 주기가 다시 시작됩니다.
- 취침 준비 알림을 미뤄 둔 상태에서 설정을 바꾸면, 미뤄 둔 예약은 새 설정을 따릅니다.
  간격을 바꾸면 **미루기를 누른 시각 기준**으로 다시 계산하고(이미 지났으면 곧바로 뜹니다),
  알림 시각 자체를 바꾸면 미뤄 둔 기록을 버리고 새 시각만 따릅니다.
- 취침 준비 알림은 하루에 한 번만 뜹니다. 하루의 경계는 리셋 시각(기본 01:00)이라, 취침 시각을 00:30 처럼
  자정 뒤로 잡아도 '그날 밤'으로 취급합니다. 알림 시각에 앱이 꺼져 있었다면, 그날 안에 앱을 켤 때 한 번 띄웁니다.
- 일정은 알림이 아니라 달력 창의 '다가오는 일정' 목록으로 보여줍니다. 오늘(리셋 기준) 이후 일정만 가까운 날짜순으로
  나오고, 날짜가 지나면 목록에서 빠집니다. 지난 일정도 달력에는 그대로 남아 있어 다시 볼 수 있습니다.
- 달력 창은 내용이 길면 세로로 스크롤됩니다. 창 크기를 늘리지 않아도 됩니다.
