# Warn & Alarm 서명 인증서 — 설치 내역과 제거 방법

## 무엇이 설치되어 있나

Warn & Alarm 실행 파일에 넣은 **자체 서명 인증서**입니다. 이걸 신뢰 목록에 넣어야
Windows가 "알 수 없는 게시자" 대신 게시자 이름을 보여줍니다.

| 항목 | 값 |
| --- | --- |
| 이름 | `CN=Warn & Alarm, O=Warn & Alarm, C=KR` |
| 지문 (Thumbprint) | `169ECAC79221662E83CBC397F17E6ADA263CA016` |
| 유효 기간 | 2026-09-04 ~ 2036-09-01 |
| 설치 위치 | `Cert:\CurrentUser\Root`, `Cert:\CurrentUser\TrustedPublisher` |
| 적용 범위 | **현재 사용자 계정만** (관리자 권한 없이 설치됨) |

설치 후 서명 상태는 `Valid`(서명이 검증되었습니다)로 확인했습니다.

## 제거하기

### 방법 1 — PowerShell 한 줄 (관리자 권한 불필요)

PowerShell을 열고 붙여넣으세요.

```powershell
Get-ChildItem Cert:\CurrentUser\Root, Cert:\CurrentUser\TrustedPublisher |
  Where-Object { $_.Thumbprint -eq '169ECAC79221662E83CBC397F17E6ADA263CA016' } |
  Remove-Item
```

지워졌는지 확인:

```powershell
Get-ChildItem Cert:\CurrentUser\Root, Cert:\CurrentUser\TrustedPublisher |
  Where-Object { $_.Subject -like '*Warn*Alarm*' }
```

아무것도 안 나오면 제거된 것입니다.

### 방법 2 — 화면에서 지우기

1. `Win + R` → `certmgr.msc` 입력 → 엔터
2. 왼쪽에서 **신뢰할 수 있는 루트 인증 기관 → 인증서** 를 펼칩니다
3. `Warn & Alarm` 을 찾아 삭제
4. **신뢰할 수 있는 게시자 → 인증서** 에서도 같은 항목을 삭제

### 관리자 권한으로 전체 설치했던 경우

`certs\인증서-설치.ps1` 을 관리자 권한으로 실행했었다면 컴퓨터 전체(`LocalMachine`)에도
들어가 있습니다. 관리자 권한 PowerShell에서 아래를 실행하세요.

```powershell
Get-ChildItem Cert:\LocalMachine\Root, Cert:\LocalMachine\TrustedPublisher |
  Where-Object { $_.Thumbprint -eq '169ECAC79221662E83CBC397F17E6ADA263CA016' } |
  Remove-Item
```

## 제거하면 어떻게 되나

- 앱은 그대로 잘 동작합니다. 서명은 파일에 남아 있고, Windows가 그 서명을 **신뢰하지 않게** 될 뿐입니다.
- 실행할 때 다시 "알 수 없는 게시자"로 표시됩니다.
- 설정, 할 일 목록, 기록은 전혀 영향받지 않습니다
  (그건 `%APPDATA%\Warn & Alarm\warn-and-alarm.json` 에 따로 있습니다).

## 알아둘 점

- 이 인증서는 공인 기관이 발급한 것이 아니라 이 프로젝트에서 직접 만든 것입니다.
  넣어 둔 컴퓨터에서만 신뢰되고, 다른 사람 컴퓨터에서는 여전히 경고가 뜹니다.
- 개인 키는 `certs/codesign.key` 한 곳에만 있고 git에서도 제외되어 있습니다.
  이 키가 유출되면 그것으로 서명한 다른 파일도 이 계정에서 신뢰될 수 있으니,
  키 파일을 남에게 주거나 공개 저장소에 올리지 마세요. 찜찜하면 위 방법으로 지우면 됩니다.
- 키를 새로 만들면(`certs/` 를 지우고 다시 빌드) 지문이 달라져서, 예전 인증서는 지우고
  새 인증서를 다시 설치해야 합니다.

## SmartScreen 파란 화면은 별개입니다

"Windows의 PC 보호 — 인식할 수 없는 앱" 화면은 서명이 아니라 **파일에 붙는 다운로드 표시**
(Mark of the Web) 때문에 뜹니다. 인증서를 설치해도 이건 따로입니다.

- 네트워크 경로(`\\wsl.localhost\...` 등)에서 바로 실행하면 뜹니다 → 로컬 폴더에 복사해서 실행하세요.
- 인터넷에서 받은 파일이면: 파일 오른쪽 클릭 → 속성 → 아래쪽 **차단 해제** 체크 → 확인.
  또는 PowerShell에서 `Unblock-File "경로\WarnAndAlarm 1.0.0.exe"`.
